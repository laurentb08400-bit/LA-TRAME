# La Trame — Visions d’Univers

Site officiel de découverte d’un projet narratif et graphique en évolution.

Le site statique se trouve dans `docs/`. Sa publication se fait par GitHub Pages depuis la branche `main` et le dossier `/docs`.

Seuls des extraits sélectionnés sont destinés à la diffusion. Le manuscrit complet, les archives, l’atelier local et les dossiers de correction ne figurent pas dans ce dépôt.
